# Memories

## Goal

Help users preserve meaningful moments forever.

---

# Memory Types

Support:

- Photos
- Videos
- Voice Notes
- Text
- Locations
- Files

---

# Memory Information

Each memory includes:

- Creator
- Timestamp
- Bond
- Caption
- Media
- Reactions

---

# Albums

Members can organize memories into albums.

Examples:

- Trips
- Birthdays
- Anniversaries
- School
- Family
- Vacations

---

# AI Features

HeartString AI can:

- Generate captions
- Suggest titles
- Group similar memories
- Recommend storybook entries

---

# Timeline

All memories appear in a shared timeline.

Users can browse by:

- Date
- Member
- Album
- Event

---

# Storage

Media stored in Supabase Storage.

Metadata stored in PostgreSQL.

---

# Future

Memories become the foundation for:

- Storybooks
- Bond Movies
- AI Reflections
- Anniversary Recaps
