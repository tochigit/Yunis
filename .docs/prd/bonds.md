# Bond System

## Goal

The Bond is the core feature of Yunis.

Everything revolves around a Bond.

---

# Bond Ownership

Every Bond belongs equally to all participants.

No user has higher ownership than another.

Permissions depend on role, not ownership.

---

# Bond Information

Each Bond contains:

- Bond Name
- Cover Image
- Bond Type
- Anniversary
- Members
- Shared Timeline

---

# Bond Types

Examples:

- Meaningful Relationship
- Couple
- Family
- Siblings
- Parent & Child
- Mentor
- Custom

---

# Bond Customization

Members can customize:

- Bond Name
- Theme
- Accent Color
- Background
- Cover Image
- Shared Nicknames

---

# Bond Dashboard

Displays:

- Recent Memories
- Active Challenges
- Shared Calendar
- AI Insights
- Bond Level
- Milestones

---

# Bond Growth

The system tracks meaningful activity.

Examples:

- Conversations
- Memories
- Challenges
- Milestones

Growth reflects activity, not streak abuse.

---

# Bond Lifecycle

Create

↓

Invite Members

↓

Customize

↓

Grow Together

↓

Preserve Memories

↓

Generate Storybooks & Movies

---

# Rules

Deleting a Bond requires confirmation from eligible members.

Historical memories should never disappear accidentally.
