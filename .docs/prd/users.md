# Target Users

## Primary Users

People who already have an existing relationship.

Examples:

- Couples
- Best friends
- Families
- Siblings
- Long-distance relationships
- Study partners
- Gaming partners
- Accountability partners
- Other meaningful personal relationships

---

## Age

Recommended:

16+

## User Motivations

Users join Yunis to:

- Stay close.
- Create memories.
- Chat.
- Complete challenges.
- Celebrate milestones.
- Receive AI guidance.
- Preserve relationship history.
- Build stronger emotional connections.

---

## Not Designed For

- Dating strangers.
- Random matching.
- Anonymous messaging.
- Swipe culture.
