# User Profiles

## Goal

A user's profile represents their identity throughout Yunis.

Profiles should feel personal, expressive, and trustworthy.

---

# Profile Information

Each profile contains:

- Display Name
- Username
- Profile Picture
- Banner
- Bio
- Country
- Pronouns (Optional)
- Birthday (Optional)
- Join Date

---

# Customization

Users can customize:

- Profile Theme
- Profile Card
- Chat Bubble
- Profile Frame
- Badges
- Decorations

Some customizations are unlocked through:

- Hearts
- Subscriptions
- Marketplace
- Events

---

# Privacy

Users control:

- Who can view profile
- Who can send requests
- Who can message
- Online status
- Read receipts
- Last seen

---

# Statistics

Examples:

- Total Bonds
- Active Bonds
- Memories Created
- Challenges Completed
- Years on Yunis

---

# Future Expansion

Profiles should support future cosmetic upgrades without redesigning the system.
