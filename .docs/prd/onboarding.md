# Onboarding

## Goal

Get a new user connected with someone meaningful as quickly and smoothly as possible.

---

# Account Creation

User provides:

- Name
- Email
- Password
- Country

Country determines:

- Currency
- Pricing
- Regional settings

---

# First-Time Experience

Introduce:

- Yunis
- Hearts
- HeartString AI
- Bonds
- Memories
- Challenges
- Storybooks

Keep onboarding short.

---

# First Bond

After signup, encourage the user to create or join their first Bond.

Connection methods include:

- Bond Code
- QR Code
- Username
- Email
- Invite Link

---

# Empty State

Until the user creates their first Bond:

- Show helpful tips.
- Explain key features.
- Encourage invitations.

---

# Success Criteria

A successful onboarding ends when the user creates or joins their first Bond.

That is considered activation.
