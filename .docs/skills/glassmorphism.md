# Glassmorphism Skill

## Purpose

Defines Yunis's visual style.

---

# Design Direction

Premium.

Modern.

Minimal.

Soft.

Elegant.

Inspired by Apple's design language without copying it.

---

# Principles

- Soft transparency
- Subtle blur
- Rounded corners
- Gentle shadows
- Clean spacing

---

# Avoid

- Heavy borders
- Loud gradients
- Overlapping effects
- Visual clutter

---

# Goal

The interface should feel calm, premium, and emotionally warm.
