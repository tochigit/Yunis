# Animation Skill

## Purpose

Defines animation principles across Yunis.

---

# Philosophy

Animations should support the experience.

Never distract from it.

---

# Principles

- Smooth
- Responsive
- Purposeful
- Consistent

---

# Use Animations For

- Navigation
- Page transitions
- Feedback
- Success states
- Loading states
- Micro-interactions

---

# Avoid

- Long animations
- Excessive motion
- Flashing effects
- Blocking user interaction

---

# Performance

Prefer hardware-accelerated animations.

Animations should remain smooth on mid-range mobile devices.
