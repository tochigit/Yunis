# Component Builder Tool

## Purpose

Standard process for creating UI components.

---

# Inputs

- Relevant PRD
- Relevant Task
- Design requirements

---

# Process

1. Read documentation.
2. Identify reusable patterns.
3. Build component.
4. Make responsive.
5. Add accessibility.
6. Test.
7. Document if necessary.

---

# Checklist

- Responsive
- Accessible
- Reusable
- Typed
- Clean code
- No duplicated logic

---

# Output

Production-ready UI component.
