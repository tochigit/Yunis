# Code Review Tool

## Purpose

Review code before completion.

---

# Verify

- Readability
- Maintainability
- Performance
- Security
- Type safety
- Consistency

---

# Reject If

- Duplicate logic
- Hardcoded secrets
- Poor naming
- Dead code
- Unnecessary complexity

---

# Accept If

- Clean
- Modular
- Documented
- Follows standards
