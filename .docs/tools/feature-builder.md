# Feature Builder Tool

## Purpose

Standard workflow for implementing features.

---

# Inputs

- PRD
- Task
- Architecture
- Standards

---

# Process

1. Understand requirements.
2. Identify affected systems.
3. Build backend.
4. Build frontend.
5. Integrate.
6. Test.
7. Update documentation.

---

# Requirements

- Follow standards.
- Keep changes focused.
- Avoid breaking existing features.

---

# Output

Complete production-ready feature.
